PROJECT 01

GNN 기반
리뷰 스팸 탐지

경희대학교 데이터 사이언스 학회 CODE
🏆 ITDA 수도권 학술제 장려상

🥇 학회 내 팀 최우수상
발표자료 PDF 대시보드 →

리뷰 스팸 탐지를 텍스트 분류가 아닌 사용자·상품·리뷰 간 관계 기반 이상탐지 문제로 재정의한 프로젝트

Problem

온라인 플랫폼에서 리뷰 조작, 허위 리뷰, 조직적 평점 조작이 발생하면 사용자는 잘못된 정보를 바탕으로 의사결정을 하게 됩니다. 기존의 리뷰 스팸 탐지는 리뷰 텍스트 자체를 분석하는 방식이 많았지만, 조직적 리뷰 조작은 단순히 문장 표현만으로 드러나지 않을 수 있습니다.

Approach

이 프로젝트에서 중요한 부분은 GNN 모델을 적용했다는 사실보다, 리뷰 스팸 문제를 그래프 기반 이상탐지 문제로 재정의하고 어떤 관계를 그래프에 포함해야 실제 조작 행동을 포착할 수 있을지 설계한 과정이었습니다.

[User] ─── writes ───► [Review] ─── belongs to ───► [Product] │ └── similar timing / rating pattern ──► [Other Review]
  • 사용자·리뷰·상품을 노드로 구성하는 이종 그래프 구조 설계
  • 단기간 집중된 리뷰, 반복적 사용자 행동 패턴 등 관계 기반 특징 설계
  • GNN/GraphSAGE 기반 이상탐지 방향 검토 및 샘플링 전략 논의

My Role

저는 프로젝트에서 리뷰 스팸 탐지를 위한 문제 정의, 관계 기준 설계, 샘플링 방식 논의, 분석 방향 설정에 참여했습니다. 특히 리뷰 조작 행동을 단순 텍스트 문제가 아니라 사용자·상품·리뷰 간 관계에서 나타나는 이상 패턴으로 볼 수 있다는 관점에서 그래프 구조 설계 방향을 논의했습니다. 최종 대시보드 및 시각화 구현은 팀원이 주도했으며, 저는 어떤 지표와 흐름을 보여주면 분석 결과를 더 잘 전달할 수 있을지 의견을 공유했습니다.

Problem Framing Graph Relation Design Sampling Strategy Analysis Direction Dashboard Metric Discussion Presentation

Key Insight

리뷰 스팸 탐지는 개별 리뷰의 텍스트만으로 충분히 설명하기 어렵습니다. 조직적 조작 행동은 사용자, 상품, 시간, 평점 사이의 관계 구조에서 더 명확하게 드러날 수 있습니다. 따라서 문제를 어떤 데이터 구조로 재정의하느냐가 모델 선택만큼 중요합니다.

PROJECT 02

날씨와 영화 매출
데이터 분석

날씨·날짜 조건이 영화 수요에 미치는 영향을 회귀분석으로 분석하고, 지역별 수요 차이를 해석한 프로젝트

Problem

영화관 수요는 영화 콘텐츠 자체뿐 아니라 날씨, 요일, 휴일, 지역 특성 등 다양한 외부 요인의 영향을 받을 수 있습니다. 단순히 날씨가 좋거나 나쁘다는 직관적 해석이 아니라, 실제 데이터와 회귀분석을 통해 수요 변화를 설명하고자 했습니다.

핵심 질문: 폭염이나 불쾌지수는 영화 매출에 유의미한 영향을 미치는가? 주말, 문화가 있는 날은 수요를 어떻게 변화시키는가? 지역별 차이는 어떻게 나타나는가?

기상 데이터와 영화 매출 데이터를 결합하고, 날씨 및 날짜 조건이 영화 수요에 미치는 영향을 설명하기 위한 변수 설계와 회귀분석 해석에 참여했습니다. 폭염 여부, 불쾌지수, 주말 여부, 문화가 있는 날 등 외부 조건을 분석 가능한 변수로 전환하고, 지역별 수요 차이가 어떻게 나타나는지 해석하는 데 집중했습니다.

이 프로젝트를 통해 데이터 분석은 모델을 적용하는 것에서 끝나지 않고, 현상을 설명할 수 있는 변수를 어떻게 설계하느냐에 따라 인사이트의 깊이가 달라진다는 점을 배웠습니다. 같은 현상도 어떤 질문을 세우고 어떤 변수를 설정하느냐에 따라 전혀 다른 해석으로 이어질 수 있다는 경험이 이후 데이터 분석가를 꿈꾸게 된 계기가 되었습니다.

PROJECT 03

응급실 뺑뺑이
데이터 액티비즘

데이터 액티비즘 프로젝트
🌐 Claude Code 활용 웹페이지 구현

응급실 수용 거부를 정보 비대칭 + 의료 접근성 문제로 재정의하고, 데이터 스토리텔링 웹페이지로 구현한 프로젝트

Problem

응급실 뺑뺑이는 단순히 병원 수가 부족하다는 설명만으로는 충분하지 않습니다. 응급실 가용 병상, 진료 가능 여부, 지역별 의료 접근성, 사용자가 정보를 확인하는 방식 등이 복합적으로 작용합니다. 보건복지부의 "응급실 똑똑" 같은 서비스가 존재하지만, 일반 사용자가 실제 응급 상황에서 정보를 직관적으로 이해하고 활용하기 어렵다는 문제의식에서 출발했습니다.

응급 상황에서 중요한 것은 "정보가 존재하는가"뿐만 아니라, 사용자가 그 정보를 빠르게 이해하고 행동으로 옮길 수 있는가입니다.

Approach

  • 응급실 수용 거부를 의료 자원·정보 접근성·사용자 경험이 결합된 구조적 문제로 재정의
  • 공공데이터포털, 서울열린데이터광장, 응급의료통계포털, KOSIS 등 공공 데이터 활용
  • 시민 설문(39명), 응급 앱 사용성 테스트(4개 시나리오) 수행
  • 데이터 스토리텔링 방식으로 웹페이지 정보 구조 기획 및 구현

Claude Code 활용 방식

웹페이지 구현 과정에서는 Claude Code를 활용했습니다. 다만 단순히 코드를 생성한 것이 아니라, 문제 정의, 페이지 구조 설계, 정보 배치, 데이터 전달 방식, 사용자 흐름은 직접 기획했습니다. Claude Code는 기획한 구조를 실제 웹페이지로 구현하는 도구로 활용했습니다.

My Role

  • 응급실 수용 거부 문제의 구조화 및 문제 정의
  • 공공데이터 활용 방향 설정 및 데이터 수집
  • 기존 서비스 사용성 분석 및 개선 방향 도출
  • 웹페이지 정보 구조 기획 및 데이터 스토리텔링 흐름 구성
  • Claude Code를 활용한 웹페이지 구현
Problem Framing Public Data Strategy User Research Information Architecture Web Implementation Data Storytelling

Key Insight

응급실 뺑뺑이 문제는 데이터가 없어서만 발생하는 문제가 아니라, 필요한 정보가 사용자에게 적절한 방식으로 전달되지 못하는 문제이기도 합니다. 데이터 분석은 문제를 설명하는 것에서 나아가, 사용자가 이해하고 행동할 수 있는 형태로 정보를 전달하는 과정까지 포함해야 한다고 느꼈습니다.

🏅 공모전 본선 진출

중국 중심 배터리 공급망 리스크를 분석하고 K-배터리의 단기·중장기 전략 방향을 제안한 프로젝트

Problem

글로벌 배터리 산업은 전기차 시장 성장과 에너지 전환 흐름 속에서 중요한 전략 산업으로 자리 잡았지만, 배터리 원재료와 핵심 소재 공급망은 중국에 대한 의존도가 높습니다. 중국의 원재료 통제, 수출규제, 공급망 무기화 가능성은 국내 배터리 기업에 큰 리스크로 작용할 수 있습니다.

핵심 질문: K-배터리 기업이 중국 중심 공급망 의존에서 발생하는 리스크를 어떻게 관리하고, 단기적 사업 안정성과 중장기적 기술주권을 동시에 확보할 수 있는가?

Approach

  • 증권사 리포트, 컨설팅 자료, 배터리 3사 사업보고서, 산업 뉴스 분석
  • K-배터리 기업의 NCM 양산 강점과 공급망 취약성 도출
  • 단기/중장기 전략을 구분하는 이중 전략 프레임 구성

Strategy Roadmap

단기 전략
  • ESS 시장 적극 대응
  • LFP/ESS 생산라인 전환 검토
  • 가동률 및 현금흐름 방어
중장기 전략
  • 전고체 배터리 밸류체인 구축
  • 무음극체/차세대 배터리 기술 확보
  • 핵심 소재 공급망 다변화

K-배터리 기업은 NCM 양산 역량을 바탕으로 경쟁력을 확보해왔지만, 중국 중심 공급망 의존과 LFP 중심 시장 변화는 새로운 리스크로 작용하고 있습니다.

My Role

배터리 산업 현황, 핵심 지정학 리스크, K-배터리 기업의 취약성 분석을 담당했습니다. 증권사 리포트, 컨설팅 자료, 배터리 3사 사업보고서, 산업 뉴스를 바탕으로 국내 배터리 기업의 NCM 양산 강점과 중국 의존도가 높은 공급망 구조를 정리했습니다. 단기적으로 ESS/LFP 전환 가능성을 검토하고, 중장기적으로 전고체 배터리 밸류체인 구축 필요성을 전략 메시지로 정리하는 데 참여했습니다.

Industry Research Supply Chain Risk Analysis Business Report Analysis Strategic Framing Slide Writing Storyline Development

Key Insight

지정학적 리스크는 단순한 외부환경 변화가 아니라 기업의 생산, 원가, 기술 개발, 시장 전략에 직접적인 영향을 미치는 전략 변수입니다. 이 프로젝트를 통해 산업 리서치 자료를 단순 요약하는 것을 넘어, 기업의 취약성과 대응 방향을 하나의 전략 논리로 구조화하는 경험을 쌓았습니다.
