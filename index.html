01 설문 응답 현황 보고 개선

기관·직급별 설문 응답 현황을 매일 보고하면서 새 자료를 받을 때마다 수작업으로 보고를 준비했습니다. 업무에 익숙해진 뒤, 자료를 교체하면 같은 기준으로 현황을 확인할 수 있도록 Excel 보고 양식을 만들었습니다.

  • GPT의 함수 설명을 참고해 설문 아이디로 대상자와 응답 자료를 연결하고, 기관·직급 조건별 집계 구성
  • 브라우저에서 확인하는 진행 현황과 다운로드한 응답 자료를 각각 반영
  • 기존 목표값과 응답 분류 기준을 유지하고, 참조 범위·계산 결과·새 자료가 이전 보고값에 주는 영향 점검

결과 · 정해진 시트에 최신 자료를 넣어 보고를 준비할 수 있게 됐고, 사수의 확인을 받아 업무에 활용했습니다.

02 보고서 검수와 지침 요약

조사 보고서에서는 결과표와 본문의 수치·전년 대비 증감을 대조하고, 조사 결과와 개선과제의 연결을 확인했습니다. 검토가 필요한 부분은 메모와 도형으로 표시해 사수가 위치와 내용을 쉽게 찾도록 정리했습니다.

사업 지침의 주요 부분을 표시해 달라는 요청에는 별도 요약본을 제안했습니다. GPT로 초기 틀을 구성한 뒤 원문을 읽으며, 사수가 이미 아는 기본 내용보다 변경·추가·삭제 사항을 우선 정리했습니다.

결과 · 지침 요약본은 추가 수정 요청 없이 다음 날 회의에 활용됐습니다. 제언서 초안 작성에서는 전년도 보고서와 이번 조사 결과를 함께 검토해 개선과 후속 점검 사항을 정리했습니다.

03 주민설명회 현장 대응

행사 전날 밤 물품 변경 요청이 들어와 수령 일정과 사전 검수 시간이 촉박해졌습니다. PM이 공급처 협의를 진행했고, 저는 사수와 새벽 수령을 맡아 행사 준비에 참여했습니다.

사수와 파손 가능성을 고려해 여유분을 준비했고, 실제 파손이 발생했을 때 대응해 행사 시작 전 준비를 마쳤습니다. 이후 출장에서는 발표자·스태프·청중의 동선을 고려해 물품을 배치하고, 결과보고서에 필요한 사진을 직접 촬영해 초안 작성에 활용했습니다.

배운 점 · 필요한 일을 빠르게 처리하는 데서, 행사 흐름과 다음에 필요한 준비를 함께 살피는 방식으로 일하게 됐습니다.

추가 담당 업무

환자경험평가 조사에서는 참여자 문의용 카카오톡 채널과 챗봇 메뉴·자동응답을 구성하고 동작을 점검했습니다. 안내 문자와 설문조사 페이지를 통해 이용 방법을 알리고, 조사 일정 편성과 전화 설문 녹음본 검수도 지원했습니다.

15장·10분 제한 안에서 캐즘과 국내 기업의 상황을 먼저 설명한 뒤 대응전략으로 이어지도록 구성을 정리하고 발표를 맡았습니다.

조사에서 결과물로

팀은 정보의 존재 여부뿐 아니라 서비스 인지도와 실제로 정보를 찾는 과정을 함께 살폈습니다. 조사 결과를 지도·차트·설명으로 보여주는 웹페이지를 제작하고, 응급똑똑 서비스를 알리는 SNS 캠페인으로 연결했습니다.

저는 서로 다른 조사 내용을 한 페이지의 흐름으로 정리하면서, 데이터를 보여주는 것과 이용자가 그 의미를 이해하도록 설명하는 작업을 함께 경험했습니다.

해석의 범위

39명의 설문 결과는 참여자들의 인식을 보여주는 탐색 자료로 활용했습니다. 이를 전체 시민의 의견으로 일반화하거나, 정보 접근성만으로 응급실 뺑뺑이의 원인을 설명하지 않았습니다. 웹페이지는 조사 결과를 전달하는 결과물입니다.

리뷰 사이의 관계를 어떻게 정의하고, 탐지 결과를 어떤 지표로 읽을지 논의했습니다.

문제와 분석 접근

사용자·상품·리뷰 사이의 관계를 활용해 의심스러운 리뷰 패턴을 탐지하는 팀 프로젝트입니다. YelpZip 데이터를 바탕으로 여러 관계를 연결한 그래프 신경망(GNN)을 적용하고, 리뷰 스팸 탐지 성능을 평가했습니다.

내가 기여한 부분

관계 기준과 샘플링 방식에 대한 논의에 참여하고, 결과를 보여줄 대시보드의 지표와 구성에 의견을 제시했습니다. 최종 대시보드와 시각화 구현은 팀원이 주도했습니다. 저는 분석 결과를 이해하기 위해 데이터가 어떤 기준으로 연결되고 평가되는지 살피는 데 집중했습니다.

분석 질문과 데이터

날씨와 날짜 조건이 영화 매출·관객 수와 어떤 관계를 보이는지 분석했습니다. 2022~2024년 기상청 자료와 KOFIC 영화관입장권통합전산망의 일별 데이터를 결합하고, 서울·경기·인천의 지역별 관객 비중도 함께 살폈습니다.

담당한 분석 과정

R을 활용한 자료 결합, 변수 구성, 회귀분석과 결과 해석에 참여했습니다. 강수·기온·불쾌지수 등 기상 조건과 주말·문화가 있는 날 등 날짜 조건을 변수로 구성하고, 매출·관객 수·지역별 비중을 각각 살폈습니다.

팀 분석에서 확인한 결과

  • 매출·관객 수 모형에서 주말과 문화가 있는 날이 양의 관계를 보임
  • 지역별 관객 비중 모형에서는 주말의 계수가 서울은 음수, 경기는 양수로 나타남
  • 모형별 설명력을 비교해 같은 변수로 모든 결과를 충분히 설명하기 어렵다는 점 확인

전체 수요와 지역별 비중을 나눠 보면서, 분석 대상에 따라 같은 변수의 해석이 달라질 수 있음을 배웠습니다. 지역별 비중 차이만으로 관객이 실제로 이동했다거나 날씨가 소비 변화를 일으켰다고 단정할 수는 없습니다.

분석 조건과 보완점

불쾌지수를 범주화한 방식과 변수 간 다중공선성에 따른 상호작용항 제외를 한계로 정리했습니다. 결과를 설명할 때 어떤 변수를 포함했고 어떤 단위로 비교했는지 함께 밝혀야 한다는 점을 익혔습니다.
