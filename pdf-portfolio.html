PROJECT 01 · Industry Research · Strategy
K-배터리 지정학적 리스크 전략 분석
경희대학교 BACS 비즈니스 애널리틱스 학회 · 지정학적 리스크 전략 공모전
이동현
🏅 공모전 본선 진출
중국 중심 배터리 공급망 리스크를 분석하고 K-배터리의 단기·중장기 전략 방향을 제안한 프로젝트
Problem

글로벌 배터리 공급망은 중국 의존도가 높으며, 원재료 수출규제·공급망 무기화 가능성이 K-배터리 기업에 큰 리스크로 작용합니다. NCM 양산에 강점이 있으나 LFP 중심 시장 변화와 공급망 취약성을 동시에 해결해야 하는 과제가 있었습니다.

Approach
  • 증권사 리포트, 컨설팅 자료, 배터리 3사 사업보고서 분석
  • 지정학적 리스크 구조화 및 K-배터리 취약성 도출
  • 단기/중장기 이중 전략 프레임 구성
Strategy Roadmap
단기 전략
  • ESS 시장 적극 대응
  • LFP/ESS 생산라인 전환 검토
  • 가동률 및 현금흐름 방어
중장기 전략
  • 전고체 배터리 밸류체인 구축
  • 무음극체/차세대 배터리 기술 확보
  • 핵심 소재 공급망 다변화
My Role

배터리 산업 현황, 핵심 지정학 리스크, K-배터리 기업 취약성 분석 담당. 산업 리서치 자료를 핵심 리스크와 전략 메시지로 구조화하는 데 참여했습니다.

Industry Research Supply Chain Risk Analysis Strategic Framing Slide Writing Storyline Development
Key Insight: 지정학적 리스크는 단순한 외부환경 변화가 아니라 기업의 생산·원가·기술 개발· 시장 전략에 직접적인 영향을 미치는 전략 변수입니다. 산업 리서치 자료를 단순 요약하는 것을 넘어, 기업의 취약성과 대응 방향을 하나의 전략 논리로 구조화하는 경험을 쌓았습니다.

PROJECT 02 · Regression Analysis · Demand Analysis
날씨와 영화 매출 데이터 분석
경희대학교 Business Analytics 수업 · 2022~2024년 서울·경기·인천 일별 데이터
이동현
날씨·날짜 조건이 영화 수요에 미치는 영향을 회귀분석으로 설명하고 지역별 수요 차이를 해석한 프로젝트
Problem

영화 수요는 콘텐츠 자체뿐 아니라 날씨, 요일, 지역 생활 패턴 같은 외부 조건에 달라질 수 있습니다. 폭염·불쾌지수·강수 여부와 같은 기상 조건과 주말·문화가 있는 날 등의 날짜 요인을 실제 데이터로 검증하고 비즈니스 인사이트를 도출하고자 했습니다.

Data & Variables
  • 기상청 일별 기후 데이터 + KOFIC 영화 매출 데이터
  • 폭염 여부, 불쾌지수, 강수량, 주말·공휴일·문화가 있는 날
  • 서울/경기/인천 지역별 관객 수·매출 비중
Key Results
Adj R² 0.32
회귀모델 설명력
주말 효과 유의
매출·관객 수 정(+)의 영향
서울↓ 경기↑
주말 지역 수요 이동 패턴
  • 불쾌지수: 영화 수요에 정(+)의 영향 — 더운 날 실내 여가 선택 경향
  • 강수 변수: 통계적으로 유의하지 않은 것으로 나타남
My Role

기상 데이터와 영화 매출 데이터 결합, 변수 설계, 회귀분석 수행, 지역별 수요 차이 해석 참여. 외부 조건을 분석 가능한 변수로 전환하는 과정에 집중했습니다.

Data Cleaning Data Merging Variable Design Regression Analysis Regional Demand Analysis Business Insight
Key Insight: 데이터 분석은 모델을 적용하는 것에서 끝나지 않고, 현상을 설명할 수 있는 변수를 어떻게 설계하느냐에 따라 인사이트의 깊이가 달라집니다. 이 프로젝트는 데이터 분석가를 꿈꾸게 된 계기가 된 프로젝트입니다.

PROJECT 03 · Graph Machine Learning · Anomaly Detection
GNN 기반 리뷰 스팸 탐지
경희대학교 데이터 사이언스 학회 CODE
이동현
🏆 ITDA 수도권 학술제 본선 진출 및 장려상 🥇 학회 내 팀 최우수상
리뷰 스팸 탐지를 텍스트 분류가 아닌 사용자·상품·리뷰 간 관계 기반 이상탐지 문제로 재정의한 프로젝트
Problem Reframing

기존: 리뷰 텍스트를 분류해 스팸 탐지
우리의 접근: 사용자·상품·리뷰 간 관계 구조에서 나타나는 이상 패턴 탐지

조직적 리뷰 조작은 단순 문장 표현보다 관계 구조에서 더 명확하게 드러날 수 있습니다.

Approach
  • User · Review · Product 이종 그래프 구조 설계
  • 단기 집중 리뷰, 반복 행동 패턴 등 관계 기반 특징 설계
  • GNN/GraphSAGE 기반 이상탐지 방향 검토
  • 샘플링 전략 논의 및 분석 방향 설정
Graph Structure
[User] ─── writes ───► [Review] ─── belongs to ───► [Product]
                │
                └── similar timing / rating ──► [Other Review]
My Role

문제 정의, 그래프 관계 기준 설계, 샘플링 방식 논의, 분석 방향 설정에 참여. 최종 대시보드 및 시각화 구현은 팀원이 주도했으며, 어떤 지표와 흐름을 보여줄지 의견을 공유했습니다.

Problem Framing Graph Relation Design Sampling Strategy Analysis Direction Dashboard Metric Discussion
Key Insight: 문제를 어떤 데이터 구조로 재정의하느냐가 모델 선택만큼 중요합니다. 조직적 조작 행동은 텍스트보다 사용자·상품·시간의 관계 구조에서 더 명확하게 드러날 수 있습니다.

PROJECT 04 · Public Data · Data Storytelling · Web Prototype
응급실 뺑뺑이 데이터 액티비즘
데이터 액티비즘 프로젝트 · Claude Code 활용 웹페이지 구현
이동현
응급실 수용 거부를 정보 비대칭 + 의료 접근성 문제로 재정의하고 데이터 스토리텔링 웹페이지로 구현한 프로젝트
Problem Reframing

기존 인식: 응급실 수용 거부 = 병원 또는 개인의 문제
우리의 정의: 지역별 의료 자원 분포 + 실시간 정보 접근성 + 사용자 경험이 결합된 구조적 문제

정보가 "존재하는가"뿐 아니라, 사용자가 그 정보를 빠르게 이해하고 행동으로 옮길 수 있는가가 핵심입니다.

Approach
  • 공공데이터포털, 서울열린데이터광장, KOSIS 등 활용
  • 시민 설문 39명, 응급 앱 사용성 테스트 4개 시나리오
  • 기존 "응급실 똑똑" 서비스 사용성 분석 및 개선 방향 도출
  • 데이터 스토리텔링 방식 웹페이지 구조 기획 및 구현
Claude Code 활용 방식

웹페이지 구현에 Claude Code를 활용했습니다. 단, 문제 정의·페이지 구조 설계·정보 배치· 데이터 전달 방식·사용자 흐름은 직접 기획했으며, Claude Code는 기획한 구조를 구현하는 도구로 활용했습니다.

My Role

문제 구조화, 공공데이터 활용 방향 설정, 사용성 분석, 웹페이지 정보 구조 기획, 구현 주도.
